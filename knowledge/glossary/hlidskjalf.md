# Hlidskjalf — Odin's Throne

The pack's watchtower for dispatched agents: a real-time monitor for GKE agent-sandbox Jobs.
Lists every dispatched job, streams each session's logs live, and reads verdicts aloud. The name
is Odin's high seat — the gift of seeing all the realms at once.

- The plugin surface runs inside the Hermes desktop app.
- The web surface serves at the new hall once promoted (see [the two halls](the-two-halls.md)).
